Reconcile

Automated receipt-to-transaction matching, with a human in the loop only when it matters.

Reconcile is an LLM-based agent that matches bank transactions to receipts, asks a clarifying question only when something is genuinely ambiguous, and remembers vendor aliases so it never asks the same question twice.

How it works
1

Ingest

Upload a bank CSV and a folder of receipts. The agent parses both into structured records.

2

Score candidates

Each transaction is scored against receipt candidates on amount, date proximity, and vendor similarity.

3

Decide or ask

High-confidence matches are applied automatically. Genuinely ambiguous cases get a single, specific clarifying question.

4

Remember

Vendor aliases are saved from past answers, so the same question never gets asked twice.
